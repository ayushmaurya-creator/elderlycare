# 🩺 Elderly Care – Smart Elderly Care & Medication Management Platform

A collaborative, voice-enabled healthcare ecosystem designed to help elderly individuals manage daily medications and doctor appointments independently while keeping family members and caretakers informed in real time.

**[Click Here to View Live Prototype]((https://ayushmaurya-creator.github.io/elderlycare/))** *(Demo Caretaker PIN: `1234`)*

---

## 🌟 How We Go Beyond a Basic Reminder App
1. **🎙️ Hindi/Hinglish Voice Confirmation (Web Speech API):** Elderly users don't need to struggle with typing or small buttons—they can simply speak *"Maine dawa kha li"* to log their dose, accompanied by audio confirmation.
2. **❤️ Elderly Autonomy & Decision Centre:** Keeps elderly individuals at the centre of their healthcare decisions. With one tap, they can report medication side-effects (*"Chakkar / Problem Hai"*) or request a delayed dose, immediately updating the family dashboard.
3. **🔒 Passcode-Protected Caretaker Ecosystem:** Shared profile protected by a 4-digit PIN (`1234`) allowing authorized family members to view, add, edit, and delete medication schedules and doctor appointments.
4. **📊 Real-Time Adherence Tracking:** Visual progress bar calculating daily medication adherence percentage live.
5. **📧 Proactive Email Reminders:** One-click automated email alert generator for missed medications, upcoming doctor appointments, and elderly wellness updates.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (High-contrast accessible UI for seniors), Vanilla JavaScript (ES6+)
- **APIs Used:** Web Speech API (`SpeechRecognition` & `SpeechSynthesis`), `mailto` Dispatch Protocol
- **Storage:** Browser `localStorage` for real-time shared state persistence without external database latency

## 🚀 How to Run Locally
